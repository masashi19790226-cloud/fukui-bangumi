# 福井番組表（個人用 Android アプリ）

福井ケーブルテレビ（FCTV）で見られる番組の番組表を、スマホですぐ開くための個人用アプリです。
各社の**公式の番組表ページをアプリの中でそのまま表示**します。登録・APIキー・サーバーは不要です。
アプリ（APK）は GitHub の上で自動で作られます。

| 下のタブ | 表示するページ |
| --- | --- |
| 地デジ | 番組表.Gガイド（福井：NHK総合・Eテレ・福井放送・福井テレビ ＋ 石川の HAB・MRO） |
| BS | 番組表.Gガイド（BS） |
| CS | FCTV公式の番組表 CableGate の「CATV多ch」（福井ケーブルテレビで映るCSチャンネルだけ。FCTVのチャンネル番号で表示） |
| その他（メニューから） | FCTVの番組表（CableGate 地上波・BS）、FCTVコミュニティch、チャンネルラインナップ、福井放送・福井テレビ・J:COMの番組表 |

- 開いたときは今の時間の番組表が出ます。同じタブをもう一度押すか、家のマークで今の番組表に戻ります
- 番組表を広く見せるため、操作は画面下の1段のバーにまとめています（地デジ・BS・CS・メニュー・再読込・拡大縮小）
- 赤い横線が現在時刻です（地デジ・BS・CS。数秒ごとに引き直します）
- 一番左の時刻が画面のふちで切れないよう、左に少し余白をとっています（`MainActivity.kt` の `LEFT_MARGIN` で調整）
- 地デジには、石川の HAB（北陸朝日放送）と MRO（北陸放送）の列も右に並べます（「その他・設定」でオン／オフ）
- 拡大縮小：2本指でピンチ、または下のバーの －／＋。拡大率はタブごとに記憶され、次に開いたときもそのままです。5%きざみで、最初は80%（% を押すと80%に戻る）
- 広告：番組表ページの広告枠を隠します（「その他・設定」でオン／オフ）
- 番組表を広く表示：Gガイドのロゴ・ログイン・検索欄を隠し、日付などの切り替えだけ残します（「その他・設定」でオン／オフ）
- 下のバーの「メニュー」で「戻る」「今の時間の番組表へ」「ブラウザで開く」ができます。設定とリンク集は「メニュー」→「その他・設定」
- 番組の検索や放送前の通知は、表示しているサイトの機能を使ってください

## アプリをスマホに入れる手順

1. GitHub Desktop で、変更をコミットして「Push origin」する（初回は「Publish repository」。**Keep this code private のチェックは外さなくても大丈夫**です）
2. ブラウザで GitHub の fukui-bangumi リポジトリを開き、「Actions」タブで「**アプリをビルド**」が緑のチェックになるのを待つ（5分ほど）
   - 動いていなければ「アプリをビルド」→「Run workflow」→ 緑の「Run workflow」
3. リポジトリのトップページ右側の「**Releases**」を開き、`fukui-bangumi-v1.17.○.apk`（○はビルド番号）をスマホでダウンロードしてインストール
   - 「この提供元のアプリを許可」と出たら許可してください
   - リポジトリを非公開（Private）にした場合は、スマホのブラウザで GitHub にログインしてから Releases を開いてください

新しいバージョンも同じ手順で上書きインストールできます。

## バージョン

`gradle.properties` の `appVersion` がアプリのバージョンです。APK の名前は `fukui-bangumi-v<appVersion>.<ビルド番号>.apk` になります。
アプリ内のバージョンは「その他」タブのいちばん下に出ます。

## 表示するページを変える

`app/src/main/java/jp/personal/fukuiepg/ui/MainActivity.kt` の上の方にある

- `AppTab`（下のタブとURL）
- `LINKS`（「その他」のリンク集）

を書き換えて Push すると、新しいAPKが作られます。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 「アプリをビルド」が赤くなる | ログの最後のエラーを Claude に見せてください |
| ページが真っ白・表示が崩れる | 再読み込みボタン、または「ブラウザで開く」で確認してください |

## 注意

- 個人利用を前提にしています。各番組表はそれぞれの提供元のサイトで、その利用規約に従って閲覧してください
- このアプリは福井ケーブルテレビ・各放送局・番組表.Gガイドの公式アプリではありません
- APK の署名には、このリポジトリに入っている個人用の固定鍵（`app/debug.keystore`）を使っています。Google Play で公開する場合は専用の鍵を作り直してください
